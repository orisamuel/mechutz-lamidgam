# מחוץ למדגם — V2

חבילת handoff לקלוד קוד. גרסה זו מחליפה את הקודמת.

עקרון: ממשק של שאלון בחירות רציני; תוכן שמיד מתחיל לסטות לעולמות איזוטריים ונונסנסיים. אין תג "פארודיה", אין "התאמה פארודית", אין הסבר לבדיחה ואין מסך "מה חיבר ביניכם".

קבצים:
- `BUILD_PLAN.md` — אפיון מוצר/UX/עיצוב מלא
- `CONTENT.md` — בנק שאלות, תוצאות, צירים וטקסטים
- `PARTIES_AND_ASSETS.md` — מפלגות, ראשי רשימות, מקורות וקישורי תמונות/עמודי מקור
- `SCORING.md` — לוגיקת התאמה
- `CLAUDE_CODE_PROMPT.md` — פרומפט מוכן לבנייה

הערת תוכן: שמות הרשימות וראשי הרשימות הם מידע עובדתי. שאלות, צירים, אחוזי התאמה והטקסטים הקומיים הם מנגנון המשחק ואינם מתארים מצע אמיתי של מפלגה.
